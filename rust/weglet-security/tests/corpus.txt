# Corpus for weglet-security::assess_navigation.
#
# Format: <expect> <tab> <url>
#   ok     assess_navigation must return None
#   warn   must return Some(Warning) -- the user can continue
#   block  must return Some(Block)   -- no way through
#
# Rules of the file:
#   * "ok" entries are the false-positive budget, and it is zero. Every
#     one is a real site somebody would actually open. If a change here
#     turns one of these red, the change is wrong, not the entry.
#   * "block" is reserved for what is unambiguous: structural damage to
#     the URL, or a name that folds exactly onto a brand. Everything
#     softer is "warn", because a heuristic that cannot be dismissed is
#     a censor.
#   * Add the URL from every false-positive report to the "ok" section
#     when it is fixed. That is what stops it coming back.
#
# Malicious entries are synthetic patterns, not live phishing URLs --
# nothing here should be visited.
